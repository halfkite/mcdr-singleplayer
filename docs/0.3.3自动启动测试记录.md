# 0.3.3 / Minecraft 26.3 Fabric 测试记录

日期：2026-10-02。Java 25.0.3、Fabric Loader 0.19.5、Fabric API 0.161.0+26.3、Python 3.14.5、MCDR 2.16.0、官方 Prime Backup 1.13.1。

## 本版界面

回档画面改为原版加载界面风格，直接使用 Minecraft 的菜单背景、字体、`LoadingDotsText` 等待动画与 200×20 原生按钮。文字居中，使用原版常用灰白色。移除蓝色卡片、顶部强调线和彩色进度条；回档期间隐藏主菜单标志与闪烁标语，完成后点击按钮恢复正常主菜单。

继续显示目标存档、备份 ID、实际恢复阶段和结果；完成前不能进入目标存档，中断恢复的锁仍保留。备份选项及推荐配置数据版本保持原状，避免界面升级重新覆盖用户配置。

## 验证

- Python：53 项通过。
- Java：11 项通过，包括回档完成前的入口锁、失败和中断后的持久锁。
- 实际构建：`fabric-bridge/gradlew.bat -p fabric-bridge build --console=plain` 成功。最终 JAR 归档于 `mod-builds/20261002-124427/mcdr-singleplayer-bridge-0.3.3.jar`；之前的构建保留。
- 发行 JAR 的版本、两个 Mixin 清单和内嵌 Python 源码已核对。
- 最终真实客户端测试：`runClientGameTest` 三个入口全部通过，报告 `BUILD SUCCESSFUL in 2m 11s`。使用全新的 `.reference/auto-0.3.3-r2` 共用目录和隔离存档，不使用用户的 MCDR 或存档。

真实测试覆盖联网自动安装、主菜单等待、主玩家 owner、中文与英文界面、首次三个点击选项、备份开关、自动备份和清理配置、插件命令及补全、热重载、官方 PB 备份与导出、安全退出和回档。

暂缓真实恢复时，中文版界面显示原版等待动画及不可用的原生按钮；直接调用原生存档打开流程仍被入口锁拦截。恢复后按钮可点击，正常主菜单恢复，重新打开存档并检查钻石块、文件标记恢复。切换存档和配置导入测试继续通过。英文回档完成画面也已截图检查。

测试框架的退出调度仍采用之前记录中的夹具处理；临时等待恢复的测试插件不打包进发行 JAR。4/6 小时定时任务通过实际配置加载验证，没有等待完整周期；中断锁通过 Java 测试验证，没有人为损坏实际存档。仅验证 26.3 Fabric。
