# 0.3.8 首次安装提示与点击安装

基线：Minecraft 26.3、Fabric Loader 0.19.5、Fabric API 0.161.0+26.3、Java 25、MCDR 2.16.0。

## 行为

首次进入单人世界时，通过原生聊天说明根目录、主玩家四级权限、各存档的配置和插件数据隔离、删除存档后需手动清理的目录。未忽略时每次客户端启动显示一次说明；测试阶段须保留其他完整备份的红色警告重复三次。聊天行数有限，按 T 后可向上滚动查看最初的安装按钮。

新安装不再自动下载 PB。缺少的 PB / CB 提供官方主页与安装按钮；已有插件跳过对应的安装推荐。PB 使用官方 1.13.1；CB 使用官方 2.0.3，并安装 candy_tools 1.0.2。下载在 Python 工作线程执行，先校验固定 SHA-256，再加载上游插件与单人适配器。CB 当前存档配置和 `cb_files/` 绑定在加载前完成；PB 沿用独立的 `pb_files/`。现有其他版本保留，不能通过点击安装覆盖。

PB 已加载时在说明末尾发送配置选项；点击安装 PB 成功后立即发送同组选项：开启 PB、每 4 小时定时备份、推荐自动删除、官方文档。自动删除仍是 PB 原生的最近 40 份 / 每日 30 份 / 每周 30 份合并保留池。选择保存在当前存档配置中。

忽略设置保存于根目录 `config.json` 的 `onboardingDismissed`，客户端重新加载配置也保留，对全部存档生效。`/!!spbridge onboarding show` 主动查看不会取消忽略；安装命令为 `/!!spbridge install prime_backup`、`/!!spbridge install chunk_backup`，要求 MCDR 四级权限。

## 自动化验证

完整构建 `scripts/build.ps1` 通过：95 项 Python 测试、20 项 Java 测试。安装用 JAR 与完整包按独立时间戳归档。

- Python 测试覆盖首次提示、链接与可执行点击事件、三次警告、已有插件跳过安装、忽略持久化、按客户端区分说明、安装失败后重试、官方发行文件的固定哈希、当前存档绑定、不同版本保留、解压插件识别，以及全新安装器只激活桥接插件。
- Java 测试覆盖 Python 保存的忽略状态、客户端标识及令牌在游戏重启时保留。
- `runClientGameTest` 在隔离游戏目录中实际运行了首次说明、PB 下载加载后显示配置按钮、CB 与 candy_tools 下载加载、命令同步、忽略提示、PB 设置保存、备份、回档进度与入口锁、重新进入和切换存档、配置导入。真实官方插件未修改。
- 设置 `MCDR_BRIDGE_TEST_PREINSTALLED=1` 的真实客户端流程也通过：预装 PB / CB 时不显示两个安装按钮，说明和三次警告保留，PB 配置按钮直接显示。
- 首次运行的测试探针因 PB 尚未安装被 MCDR 按依赖规则卸载；测试调整为安装 PB 后主动加载测试探针，随后完整流程通过。

## 人工检查

1. 在独立测试实例安装 JAR 与 Fabric API；进入测试存档，按 T 检查完整说明、三次警告、PB / CB 链接和安装按钮。
2. 点击安装 PB，等待成功，确认四个配置按钮；开启定时备份与自动删除，重新进入后确认配置仍生效。不要删除唯一的存档备份来验证清理。
3. 点击安装 CB，确认 `!!cb` 可补全、当前存档有 `cb_files/`，在测试存档执行 `!!cb make`。
4. 点击忽略，重新进入、切换测试存档及重启游戏，确认不再主动提示；使用 `onboarding show` 仍可查看。
5. 已安装 PB / CB 的实例仅显示缺少插件的安装推荐。网络故障时显示安装失败并可重试；不同插件版本保留并提示兼容性问题。

未在本轮重新验证真实网络故障下每个镜像的可用性；镜像回退与哈希拒绝由自动化测试覆盖。未测试其他 Minecraft 版本或加载器。
