# 0.3.10 多版本兼容与发布记录

## 范围

Minecraft Java 版 1.21–1.21.11，以及 26.1、26.1.1、26.1.2、26.2、26.3，支持 Fabric 与 NeoForge 客户端

详细依赖版本见 `compat/versions.json`，1.21.x 使用 Java 21 字节码，26.x 使用 Java 25 字节码

三种介绍语言分别为 `README.md`、`README_zh_tw.md`、`README_en.md`，开头提供许可证、CurseForge、GitHub 下载、Minecraft 版本与相关项目链接

## 实现

- 游戏端基线源码保留在 `fabric-bridge/`，通过 `scripts/generate_compat.py` 生成每个版本的独立实现，旧版保存退出、图形渲染和命令刷新接口分别适配
- NeoForge 的客户端 tick、消息、命令注册、玩家加入离开和内置服务端生命周期由 `scripts/neoforge_compat.py` 生成对应事件桥接
- 每个适配按具体游戏版本编译，再合并为 `1.21.x` 与 `26.x` 系列 JAR，每个加载器两个包
- `VersionSelector` 选择明确登记的版本，`VariantMixins` 只加载该版本的两个回档 Mixin；旧版 Fabric 另带独立 refmap
- Python 安装器、MCDR 代理、Prime Backup / Chunk Backup 适配器、图标和三种客户端语言共用，不复制成不同语义的分支
- 运行目录继续使用根目录共用配置和插件、`date/<存档文件夹名>/` 原生插件数据、`log/` 日志与 `runtime/` 运行环境，PB 备份位于对应存档的 `pb_files/`
