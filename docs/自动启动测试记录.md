# 0.3.4 / Minecraft 26.3 Fabric 测试记录

> 本页保留 0.3.4 的历史验证记录。0.3.5 的目录整理、备份文件清理和最新验证结果见 [0.3.5 测试记录](0.3.5自动启动测试记录.md)。

日期：2026-10-02。Java 25.0.3、Fabric Loader 0.19.5、Fabric API 0.161.0+26.3、Python 3.14.5、MCDR 2.16.0、官方 Prime Backup 1.13.1。

## 改动

模组 ID、显示名称和 JAR 名称改为 `mcdr-singleplayer`。所有活动配置集中于游戏实例的 `mcdr-singleplayer/`，模组设置为 `config.json`，共用 MCDR 设置、权限和插件存于同一根目录。各存档的配置、数据、备份和日志直接分类于 `<存档文件夹名>/`，移除 `worlds/` 中间层与自定义外置共用目录选项。

旧模组设置与状态移走；原共用插件、权限、存档分类和备份以保留来源的方式导入。新设置优先，旧设置在新根目录归档，回档入口锁合并。源控制器仍在运行或目标数据冲突时拒绝导入。延迟迁移时仍监视旧回档，锁状态仅写入新根目录，直到回档完成才可进入。

推荐配置的数据版本继续使用 0.3.2，避免路径或名称升级重置用户的备份开关、自动备份、清理策略和自定义间隔。

## 验证

- Python：64 项通过，包含实际 MCDR 集成、手动安装和升级、中文存档名、SQLite 数据迁移、源控制器互斥、冲突拒绝和迁移续接。
- Java：16 项通过，包含新建配置的唯一位置、旧令牌迁移、新配置优先、入口锁合并与延迟迁移时的入口保护。
- 实际构建：`fabric-bridge/gradlew.bat -p fabric-bridge build --console=plain` 成功。最终 JAR 归档于 `mod-builds/20261002-143523/mcdr-singleplayer-0.3.4.jar`；此前构建保留。
- 发行 JAR 的名称、ID、版本、旧版冲突声明、两个 Mixin 和内嵌 Python 源码已核对。
- 最终真实客户端：`runClientGameTest` 三个入口全部通过，`BUILD SUCCESSFUL in 2m 20s`。使用 Gradle 创建的隔离游戏实例，MCDR 数据位于该实例的 `mcdr-singleplayer/`，未使用用户的专用服务器或真实存档。

客户端实测覆盖联网自动安装、主菜单等待、owner 权限、客户端语言、三个点击选项、备份开关、4 小时和清理配置、全部插件命令注册及补全、热重载、官方 PB 备份、导出、安全退出与回档。回档中原生界面禁用按钮并拦截原生存档打开入口；完成后重新进入，检查钻石块和文件标记恢复。第二存档的数据独立，配置导入重新绑定世界且不复制备份数据库。

最终目录检查确认：模组配置仅在 `mcdr-singleplayer/config.json`；无旧模组配置，无 `worlds/` 中间层；两个存档都有各自的 PB 数据库和存储路径。见 [目录证据](assets/automatic-0.3.4-layout.json)。

另执行 `scripts/test_legacy_pb_migration.py`：复制 0.3.3 实测留下的真实 PB 数据库与文件池到隔离旧目录，再迁移到新的存档分类。官方 PB 1.13.1 成功读取备份 #1 并导出 51 个条目，开启文件池内容校验；导出的标记为备份中的 `before`，包含 `level.dat`，原数据库 SHA-256 未改变。未将此历史备份恢复到实际世界。见 [迁移结果](assets/automatic-0.3.4-migration.json) 和 [日志](assets/automatic-0.3.4-migration.log)。

4/6 小时定时任务通过实际配置加载验证，没有等待完整周期。持久锁与迁移中断通过自动测试验证，未人为损坏实际存档。仅构建和验证 26.3 Fabric。
