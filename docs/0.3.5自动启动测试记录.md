# 0.3.5 / Minecraft 26.3 Fabric 测试记录

日期：2026-10-02。测试目标仅为 Minecraft 26.3 Fabric。

## 本次目录调整

`mcdr-singleplayer/` 根目录现在只保留三个目录：

```text
mcdr-singleplayer/
├─ date/<存档文件夹名>/   # 每个存档各自的配置、插件数据与 PrimeBackup 数据
├─ log/                   # MCDR、安装器、桥接器和各存档日志
└─ runtime/               # 共用 MCDR 配置、插件、运行环境、安装资源和状态文件
   └─ config/             # config.yml、permission.yml、config.json、plugins/
```

升级整理会把旧的 `config/`、`data/`、`plugins/`、`bridge-runtime/`、`.bridge-venv/`、`bootstrap-resources-*` 及根目录配置和状态文件迁入对应位置；旧存档配置目录里的日志放入 `log/<存档文件夹名>/`。发生同名冲突的文件会保存在 `runtime/migration-history/`。

`bootstrap-resources-0.3.4/` 是 MCDR 首次安装所需的解包资源，包含插件、PrimeBackup 适配器、Python 安装脚本和依赖清单。它不是备份数据或临时日志，更新后保存在 `runtime/bootstrap-resources-0.3.4/`。

MCDR 的 `config.yml.before-*` 是旧安装流程修改 MCDR 配置前留下的副本。现在不再生成；升级整理会移除这类旧副本。MCDR 共用配置位于 `runtime/config/`。
